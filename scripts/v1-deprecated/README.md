# Retired deployment scripts

The former v1 and v2 token deployment, upgrade, funding and integration scripts are removed. No legacy command is part of the native build or lifecycle. [The retired-file inventory](../../native/RETIRED-FILES.json) records removed paths.

Use the guarded [native local lifecycle](../../native/lifecycle/README.md) for the fresh development network. Historical testnet balances and validators are not imported or modified.
